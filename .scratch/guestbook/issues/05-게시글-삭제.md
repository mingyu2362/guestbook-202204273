# 05: 게시글 삭제

**What to build:** 작성자가 게시글의 [삭제] 버튼을 누르면 그 게시글 바로 아래에 게시글 비밀번호 입력칸이 펼쳐진다. 비밀번호가 맞으면 추가 확인 없이 게시글이 완전히 삭제되고 목록에서 곧바로 사라진다. 비밀번호가 틀리면 삭제가 거부되고 그 게시글 아래에 안내가 뜬다. 이미 삭제된 게시글이면 그 사실이 안내되고 목록이 새로 고쳐진다.

명세: [spec.md](../spec.md)의 "수정·삭제 처리 순서" 절. 비밀번호 비교 방식: [ADR-0001](../../../docs/adr/0001-게시글-비밀번호-scrypt-해시.md).

**Blocked by:** 02 (게시글 작성)

**Status:** ready-for-agent

- [x] 게시글 모듈이 `deletePost({ id, password })`를 공개하고, `{ ok: true }`, `wrong-password`, `not-found` 중 하나를 돌려준다.
- [x] 처리 순서는 다음과 같다.
  1. id로 `password_hash`만 조회한다. 행이 없으면 `not-found`를 돌려준다.
  2. 02번의 검증 함수로 비교한다. 다르면 `wrong-password`를 돌려준다.
  3. 일치하면 행을 완전히 삭제한다(soft delete 없음). 영향받은 행이 0이면 `not-found`를 돌려준다.
- [x] id가 올바른 정수가 아니면 `not-found`다.
- [x] 각 게시글에 [삭제] 버튼이 있다. 누르면 게시글 비밀번호 칸, [삭제 확인], [취소]가 그 게시글 아래에 펼쳐진다. [취소]를 누르면 아무것도 바뀌지 않은 채 닫힌다.
- [x] 04번의 인라인 폼과 함께 동작한다. 한 게시글에서는 한 번에 한 가지 모드(수정 또는 삭제)만 펼쳐진다.
- [x] Server Action과 `useActionState`로 제출하고, 제출 중에는 버튼이 비활성화된다.
- [x] 성공하면 목록 경로가 재검증되어 게시글이 목록에서 사라진다.
- [x] `wrong-password`이면 "비밀번호가 일치하지 않습니다."를 그 게시글 아래에 표시하고 비밀번호 칸을 비운다. 게시글은 그대로 남는다.
- [x] `not-found`이면 "이미 삭제되었거나 존재하지 않는 게시글입니다."를 표시하고 목록 경로를 재검증한다.
- [x] 한 게시글의 안내가 다른 게시글에 표시되지 않는다.
- [x] 두 탭을 열고, 한 탭에서 게시글을 삭제한 뒤 다른 탭에서 같은 게시글을 삭제하면 `not-found` 안내가 나오고 목록이 새로 고쳐지는 것을 확인한다.
