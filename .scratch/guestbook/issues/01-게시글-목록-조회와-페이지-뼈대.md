# 01: 게시글 목록 조회와 페이지 뼈대

**What to build:** 방문자가 방명록 페이지에 들어오면 헤더에서 개발자 정보를 확인하고, DB에 저장된 모든 게시글을 최신 작성 순으로 볼 수 있다. 게시글마다 이름, 줄바꿈이 유지된 메시지, 한국 시각 기준 작성 시각이 표시된다. 게시글이 없으면 빈 목록 대신 안내 문구가 보인다. create-next-app 초기 페이지는 이 방명록 페이지로 교체된다.

명세: [spec.md](../spec.md). 용어는 [GLOSSARY.md](../../../GLOSSARY.md)를 따른다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 저장소에 `posts` 테이블 스키마(`id` bigint identity PK, `name`, `message`, `password_hash`, `created_at` timestamptz 기본값 now(), `updated_at` timestamptz null)와 `created_at desc` 인덱스가 SQL 파일로 있고, `db:init` npm 스크립트 한 번으로 Neon DB에 적용된다. 여러 번 실행해도 안전하다.
- [x] 게시글 모듈이 `listPosts()`를 공개한다. 모든 게시글을 `created_at` 최신순으로 돌려주고, 각 항목은 `id`, `name`, `message`, `createdAt`, `updatedAt`(없으면 null)으로 이루어진다.
- [x] `listPosts()`의 쿼리는 `password_hash`를 SELECT하지 않는다.
- [x] 목록 페이지는 서버 컴포넌트에서 `listPosts()`를 직접 호출하고, 요청마다 새로 읽는다. 정적으로 캐시하지 않는다.
- [x] 헤더에 방명록 제목이 있고, 그 아래에 "조민규 · 202204273"이 표시된다.
- [x] 각 게시글에 이름, 메시지(줄바꿈 유지, HTML로 해석되지 않음), 작성 시각이 표시된다.
- [x] 작성 시각은 서버 시간대와 관계없이 Asia/Seoul 기준 `YYYY-MM-DD HH:mm (KST)` 형식으로 표시된다. 이 포맷 함수는 03번(상대 시각)과 04번("(수정됨)" 툴팁)에서 재사용할 수 있게 둔다.
- [x] 게시글이 없으면 "아직 게시글이 없습니다. 첫 게시글을 남겨 보세요." 같은 안내가 표시된다.
- [x] 페이지는 Tailwind CSS v4로 스타일링하고, create-next-app 초기 화면 요소는 남기지 않는다.
- [x] SQL로 `posts`에 행을 직접 넣으면 최신순으로 표시되는 것을 확인한다.
- [x] 구현하기 전에 프로젝트에 포함된 Next.js 16 문서에서 서버 컴포넌트의 데이터 조회와 동적 렌더링 방식을 확인한다.
